Médecins VIDAL

Licences et facturation du module de sécurisation de prescription

Table configurable uniquement par l'administrateur — les médecins n'y ont pas accès, y compris pour leur propre fiche. Base MongoDB Atlas vidal, collection medecins (les sécurisations de prescription elles-mêmes sont dans vidal.securisation).

Règle d'accès au module VIDAL

Les médecins se connectent à la plateforme par email (identifiant obligatoire et unique). À la toute première connexion d'un compte en rôle « médecin », cet email est recherché dans cette table.
• Absent → une ligne est créée automatiquement : forfait Mensuel, 25 000 FCFA, date d'enrôlement = aujourd'hui, expiration à J+30, état ACTIF.
• Présent → accès autorisé seulement si état = ACTIF ET date d'expiration non dépassée.
• Sinon (inactif, suspendu, ou expiré) → l'entrée de menu « Analyse de prescription » apparaît grisée dans le portail.
• Si l'option OTP par email est activée pour ce médecin, un code de vérification lui est envoyé par email à chaque connexion, en plus de son mot de passe habituel.

Simuler une connexion médecin

La connexion se fait par email — c'est ce qui est recherché dans la table. Le nom n'est utile ici que pour préremplir la fiche si aucun compte n'existe encore.

Journal des appels API VIDAL

Journal détaillé, réservé à l'administrateur : chaque appel au serveur VIDAL est tracé avec l'identité du médecin, la route appelée, l'horodatage, l'adresse IP et le terminal d'origine. L'adresse MAC n'est pas capturable depuis un navigateur web, quel que soit le site — aucune API JavaScript n'y donne accès (restriction imposée par les navigateurs eux-mêmes, pour la vie privée) ; seule une solution installée sur le poste (agent réseau, VPN d'entreprise) pourrait la fournir, hors périmètre d'une application web.
