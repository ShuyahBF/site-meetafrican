Journal des appels à l'API VIDAL — accès réservé à l'administrateur

Chaque appel au serveur VIDAL est tracé avec l'identité du médecin, la route appelée, l'horodatage, l'adresse IP et le terminal d'origine. L'adresse MAC n'est pas capturable depuis un navigateur web, quel que soit le site — aucune API JavaScript n'y donne accès (restriction imposée par les navigateurs eux-mêmes, pour la vie privée) ; seule une solution installée sur le poste (agent réseau, VPN d'entreprise) pourrait la fournir, hors périmètre d'une application web. Affichée ci-dessous à titre indicatif pour documenter cette limite plutôt que de l'omettre silencieusement.
